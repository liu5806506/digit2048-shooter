## V-20261006（2026-10-06，已提交 TapTap 审核）

### 玩法与平衡性

- **新增平衡性分析工具** `tests/balance.js`：3 套 AI 策略（随机 / 贪心 / 1 层前瞻）+ 关键数值敏感度扫描，量化难度曲线与"技术差距"
- **合成解锁阈值上移**：`combineStartValue` 从 9（512）→ 12（4K），让 "2048" 回归为入门关卡而非终点
- **难度旋钮警示**：在 `conf.js` / `model.js` 的 `gap`、`RNG` 等关键参数处加注释，附敏感度数据，禁止后续误调

### 性能

- **方块预渲染缓存**：32 种方块预先绘制到离屏 canvas，消除每帧约 120 次 `createLinearGradient` 调用
- **背景离屏缓存**：背景、棋盘面板、轨道等静态元素统一缓存，仅尺寸变化时重建
- **算法改进**：
  - `ArrayTool.shuffle` 改用 Fisher-Yates 无偏洗牌
  - 合并查重 `Array.includes` → `Set.has`（O(n) → O(1)）

### 视觉

- **合成粒子飞溅**：合成时迸发 8–12 个同色粒子，带重力下坠与淡出（约 0.5s）
- **修复既有显示 bug**：`BlockDrawer.format()` 由 1000 进制改回 1024 进制，游戏标题 "2048" 现在正确显示为 **2048**（而非 "2.0K"）
- **修复发射器跟随 bug**：`Born.aiming` 未初始化导致发射器方块在拖动时不跟随手指

### 音效

- **变调合成音**：5 档五声音阶（A4–C5–D5–Eb5–G5），合成多大块就发多高音
- 连击时合成音与连击音叠加，听感层次分明

### 质量保障

- 4029 项回归测试全部通过
- `dist/` 重建：37 文件 / 0.46 MB
